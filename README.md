# BookTracker — Трекер книг и чтения

Приложение для учёта прочитанных и запланированных к прочтению книг с возможностью автоматического получения данных по ISBN, анализом статистики и визуализацией.

## 📦 Требования

- Python 3.8+
- Библиотеки: `aiohttp`, `pandas`, `matplotlib`

Установка зависимостей:
```bash
pip install -r requirements.txt
