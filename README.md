Приложение для учёта прочитанных и запланированных к прочтению книг.  
Позволяет:
- добавлять книги вручную или по ISBN (через Open Library API)
- отмечать статус (в планах / читаю / прочитано)
- анализировать статистику чтения
- строить графики по жанрам и динамике
- сохранять данные между запусками
